# Code of conduct

We want this project to be a respectful, useful place to collaborate.

Participants must:

- be considerate and constructive;
- critique ideas and code rather than people;
- avoid harassment, discrimination, threats, and unwanted personal attention;
- respect privacy and do not post confidential or identifying information;
- accept maintainer decisions about project scope and moderation.

Maintainers may edit or remove contributions and restrict participation when
behavior violates these expectations. Report conduct concerns privately to the
repository maintainers through GitHub.
